# 托育中心运营协同

市级统筹的托育综合服务中心运营协同系统核心。所有业务事实落成**有序、幂等、只追加**的事件，
各业务域从事件流投影当前状态，决策事件携带规则版本号，支撑"1+N"网络下中心、社区嵌入式
点位和用人单位办托的协同运营。

## 运行检查

```sh
npm test
```

## 结构

| 模块 | 职责 |
| --- | --- |
| `src/contract.js` + `contracts/` | 各参与方确认的事件信封（`event_id/kind/occurred_at/subject_id/version`） |
| `src/store.js` | 只追加事件存储：`event_id` 去重、每个 subject 按 `version` 排序；`explain` 输出带规则版本的溯源时间线 |
| `src/rules.js` | 规则版本簿：名额、费率、期限等按版本发布、按生效时点解析 |
| `src/sites.js` | 项目节点与点位状态：竣工后一年内运营的期限、延期标记 |
| `src/slots.js` | 场地班型与全日托/半日托/计时托名额，家庭可见的真实可预约状态 |
| `src/settlement.js` | 计时托签到与结算：跨午夜分段、改期按实际时段、收费减免、防重复扣费 |
| `src/consent.js` | 家长授权与儿童健康资料调阅、安全/医疗记录的追加更正 |
| `src/staff.js` | 保育人员培训资质核验、调班 |
| `src/rectification.js` | 消防/食品/伤害预防检查与监督整改 |
| `src/operations.js` | 签约服务包、社区活动、转介 |
| `src/kinds.js` | 全部事件种类登记 |

## 关键设计

- **延期隔离**：每个中心/点位是独立 subject，某中心竣工延期只改写自己的事件流，
  已运营的社区点位状态与名额不受影响（`portfolioView` 逐点位独立投影）。
- **计时托结算**：以实际签到签退时段为准，跨午夜按东八区本地零点拆段，
  每段适用该段开始时刻生效的费率版本；改期只改计划时段，不影响结算口径；
  `charge_id = 会话:日期` 为幂等键，重复结算、重复上报不产生重复扣费。
- **授权与记录**：儿童健康资料仅承担服务的机构凭有效授权调阅，调阅留痕；
  家长撤回授权后立即停止共享，但撤回前的授权状态可还原用于合规核对；
  已形成的安全/医疗记录只能追加更正（`RECORD_CORRECTED`），原记录永不抹去。
- **乱序与重复**：断网签到、监管回执、调班等乱序到达的事件按 `version` 还原顺序；
  重复 `event_id` 直接忽略。
- **规则溯源**：预约、扣费、整改结论等决策事件都写入 `rule_version`，
  中心负责人可用 `explain(subject)` 回答"这个名额/照护决定/整改结论基于哪一版规则"。
- **时间口径**：时间比较一律按时刻（`Date.parse`），不按字符串字典序，
  避免 `Z` 与 `+08:00` 混用时误判先后。
